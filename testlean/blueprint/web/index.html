Blueprint: a proof map for exchangeable Hoeffding bounds

This page connects the draft paper's notation, proof structure, and Lean declarations. The paper is not yet on arXiv; the blueprint is a working map for turning the statistical proof into a checked Lean 4 artifact.

What this page is trying to show

The project is meant as a first foundation for using proof assistants in modern statistics: not by hiding analytic gaps behind axioms, but by naming the exact mathematical obligations and checking the logical reductions around them.

Paper layer Theorem 2.1, Hamming-slice reduction, two-level extremizers, hypergeometric MGF bound.
Lean layer Definitions of the statistic, exchangeability, \(\Gamma_N\), slice functionals, and a no-global-axiom interface.
Verification boundary The main theorem is derived from ProofObligations; the obligations are the remaining targets, not trusted axioms.

Main theorem: paper statement versus Lean statement

Paper theorem

Let \(X_1,\ldots,X_N\in[-1,1]\) be exchangeable and \(\overline X_N=N^{-1}\sum_iX_i\). Then for all \(n\le N\), \(w\in\R^n\), and \(\lambda\in\R\),

\[ \E\exp\left\{\lambda\sum_{i=1}^{n} w_i(X_i-\overline X_N)\right\} \le \exp\left\{\frac{\lambda^2}{2}\Gamma_N \|\proj\widetilde w\|_2^2\right\}. \]

Lean theorem

proved conditionally from obligations 
theorem theorem_2_1 (P : ProofObligations)
    {N n : ℕ} (hN : 2 ≤ N) (hn : n ≤ N)
    (μ : Measure (Fin N → ℝ)) [IsProbabilityMeasure μ]
    (hEx : Exchangeable μ) (hBd : BoundedByOne μ)
    (w : Fin n → ℝ) (lam : ℝ) :
    (∫ x, Real.exp (lam * centeredWeightedSum hn w x) ∂μ) ≤
      Real.exp (((lam ^ 2) / 2) * Gamma N *
        normSq (projOnePerp (zeroPad hn w)))
Interpretation. The Lean theorem is deliberately conditional: it says that once the listed analytic and combinatorial obligations are supplied, the main centered weighted bound follows by kernel-checked reasoning.

Proof architecture

The proof of Theorem 2.1 in the paper proceeds through the following chain. Each step below states the paper idea and the Lean object that currently represents it.

1

Centering becomes a projected dot product

Set \(a=\proj\widetilde w\). Then \(\sum_iw_i(X_i-\overline X_N)=a^\top X\) and \(\sum_i a_i=0\). This is the deterministic bridge from the statistical statement to the zero-sum MGF theorem.

\[ T_w(x)=\left\langle \proj\widetilde w,x\right\rangle, \qquad \sum_i(\proj\widetilde w)_i=0. \] 
centeredWeightedSum_eq_dot_proj :
  centeredWeightedSum hn w x =
    dot (projOnePerp (zeroPad hn w)) x

sum_projOnePerp_eq_zero :
  ∑ i : Fin N, projOnePerp z i = 0
2

Exchangeability reduces the MGF to vertices of the cube

Symmetrize over permutations. Because the law is exchangeable, the MGF equals an average over permuted coordinates. Convexity then puts the worst case at a vertex \(v\in\{\pm1\}^N\). 

def Exchangeable {N : ℕ} (μ : Measure (Fin N → ℝ)) : Prop :=
  ∀ σ : Equiv.Perm (Fin N), Measure.map (permute σ) μ = μ
paper proof idea; not yet separately formalized
3

Vertices become Hamming slices

If \(v\) has \(k\) plus signs, then a random permutation turns the plus coordinates into a uniform \(k\)-subset \(S_k\). With \(y_i=2\lambda a_i\), the target becomes the slice inequality

\[ \log\E_{S_k}\exp\left\{\sum_{i\in S_k}y_i\right\} \le \frac{\Gamma_N}{8}\|y\|_2^2, \qquad \sum_i y_i=0. \] 
slice_inequality :
  Real.log (sliceAverage k
    (fun S => Real.exp (∑ i ∈ S, y i))) ≤
      (Gamma N / 8) * normSq y
4

The slice extremizer has at most two levels

The slice MGF is written through the elementary symmetric polynomial functional \(F_{N,k}\). Proposition 4.4 reduces the worst case on the sphere section to vectors with two coordinate values.

\[ F_{N,k}(y)= \log\left( \frac{e_k(e^{y_1},\ldots,e^{y_N})}{\binom Nk} \right). \] 
def sliceFunctional {N : ℕ} (k : ℕ)
    (y : Fin N → ℝ) : ℝ :=
  Real.log (elemSym k (fun i => Real.exp (y i)) /
    ((Nat.choose N k) : ℝ))

proposition_4_4 :
  ∃ y, SphereSection ρ y ∧ AtMostTwoValues y ∧
    ∀ z, SphereSection ρ z →
      sliceFunctional k z ≤ sliceFunctional k y
5

Two levels leave a hypergeometric count

For a two-level vector, \(\sum_{i\in S_k}y_i\) is a centered hypergeometric count. Lemma 4.5 supplies the martingale MGF estimate with the exact finite-population factor.

\[ \log\E e^{t(H-m\mu)} \le \frac{t^2}{8}B_{N,m}, \qquad B_{N,m}=(N-s)^2 \sum_{\ell=N-s}^{N-1}\ell^{-2}. \] 
lemma_4_5_hypergeom_mgf :
  Real.log (hypergeomMgf N K m t) ≤
    (t ^ 2 / 8) * hypergeomB N m
6

Gamma evaluation, comparison, and optimality

The paper evaluates the maximum defining \(\Gamma_N\), proves \(\Gamma_N=1+3/(2N)+O(N^{-2})\), compares it to Barber's factor, and gives a lower bound showing \(1/N\) inflation is unavoidable. 

gamma_eq_closed :
  Gamma N = GammaClosed N

gamma_asymptotic :
  (fun N => Gamma N - (1 + 3 / (2 * (N : ℝ))))
    =O[atTop] (fun N => (1 : ℝ) / ((N : ℝ) ^ 2))

proposition_2_3 :
  AdmissibleConstant N C → optimalLowerBound N ≤ C

What is already checked? Lean checks that theorem_2_1 follows from the zero-sum MGF obligation and the two deterministic projection obligations. Completing the project means replacing fields of ProofObligations by actual Lean proofs.

Formalization milestones

  1. Projection algebra. Prove sum_projOnePerp_eq_zero and centeredWeightedSum_eq_dot_proj directly over Fin N.
  2. Finite computations. Verify endpoint facts such as Gamma 2 = 2 and epsilonBarber 2 = 1.
  3. Hamming-slice API. Build reusable lemmas for sliceSubsets, elemSym, and uniform slice averages.
  4. Analytic core. Formalize Hoeffding's lemma, the three-coordinate extremizer, and the hypergeometric martingale MGF bound.
