Lean 4 blueprint for a statistical proof

Exchangeable Hoeffding bounds, from paper notation to Lean objects

This page is a guided map for the draft paper A Sharper Hoeffding Bound for Weighted Sums of Exchangeable Random Variables. It explains the main theorem, the proof strategy, and the current Lean formalization boundary. The paper is not yet on arXiv.

Overview

The theorem controls the centered weighted statistic \(T_w(X)=\sum_{i=1}^n w_i(X_i-\overline X_N)\) for bounded exchangeable random variables. The variance proxy is not \(\|\widetilde w\|_2^2\), but the projected quantity \(\|\proj\widetilde w\|_2^2\), because centering removes the all-ones direction.

\[ \E\exp\{\lambda T_w(X)\} \le \exp\left\{ \frac{\lambda^2}{2}\Gamma_N \|\proj\widetilde w\|_2^2 \right\}. \]

What Lean checks now

Lean checks the logical reduction from a named proof-obligation interface to the main theorem. The hard analytic steps are not hidden as global axioms; they are visible as fields of ProofObligations.

Main theorem: paper statement versus Lean statement

Paper statement

Let \(X_1,\ldots,X_N\in[-1,1]\) be exchangeable and \(\overline X_N=N^{-1}\sum_iX_i\). Then for all \(n\le N\), \(w\in\R^n\), and \(\lambda\in\R\),

\[ \E\exp\left\{\lambda\sum_{i=1}^{n} w_i(X_i-\overline X_N)\right\} \le \exp\left\{\frac{\lambda^2}{2}\Gamma_N \|\proj\widetilde w\|_2^2\right\}. \]

Lean statement

conditional theorem 
theorem theorem_2_1 (P : ProofObligations)
    {N n : Nat} (hN : 2 <= N) (hn : n <= N)
    (mu : Measure (Fin N -> Real)) [IsProbabilityMeasure mu]
    (hEx : Exchangeable mu) (hBd : BoundedByOne mu)
    (w : Fin n -> Real) (lam : Real) :
    integral_mu (fun x =>
      exp (lam * centeredWeightedSum hn w x))
    <= exp (((lam ^ 2) / 2) * Gamma N *
      normSq (projOnePerp (zeroPad hn w)))
Why conditional? The theorem is parameterized by P : ProofObligations. This means the file does not ask Lean to trust the analytic proof for free; it records exactly what is still needed.

Proof architecture

The paper proof is not a single black box. It is a chain of reductions. The Lean file mirrors that chain by naming the objects and obligations at each stage.

1

Centering becomes a projected dot product

Set \(a=\proj\widetilde w\). The centered statistic becomes \(a^\top X\), and the vector \(a\) has coordinate sum zero.

\[ T_w(x)=\langle \proj\widetilde w,x\rangle, \qquad \sum_i(\proj z)_i=0. \] 
centeredWeightedSum_eq_dot_proj :
  centeredWeightedSum hn w x =
    dot (projOnePerp (zeroPad hn w)) x

sum_projOnePerp_eq_zero :
  sum_i (projOnePerp z i) = 0
2

Exchangeability supports symmetrization

Since the law is invariant under coordinate permutations, the MGF can be averaged over permutations. Convexity then reduces the worst case to vertices of \(\{\pm1\}^N\). 

def Exchangeable {N : Nat} (mu : Measure (Fin N -> Real)) : Prop :=
  forall sigma : Equiv.Perm (Fin N),
    Measure.map (permute sigma) mu = mu
paper proof idea; not yet a separate Lean theorem
3

Vertices become Hamming slices

A vertex with \(k\) plus signs becomes a uniform \(k\)-subset \(S_k\) after random permutation. With \(y_i=2\lambda a_i\), the target is the slice inequality.

\[ \log\E_{S_k}\exp\left\{\sum_{i\in S_k}y_i\right\} \le \frac{\Gamma_N}{8}\|y\|_2^2, \qquad \sum_i y_i=0. \] 
slice_inequality :
  log (sliceAverage k
    (fun S => exp (sum_i_in_S y_i)))
  <= (Gamma N / 8) * normSq y
4

The slice extremizer has at most two levels

The slice MGF is encoded by an elementary-symmetric-polynomial functional. Proposition 4.4 says its maximum on the zero-sum sphere occurs at a vector with at most two coordinate values.

\[ F_{N,k}(y)= \log\left( \frac{e_k(e^{y_1},\ldots,e^{y_N})}{\binom Nk} \right). \] 
def sliceFunctional {N : Nat} (k : Nat)
    (y : Fin N -> Real) : Real :=
  log (elemSym k (fun i => exp (y i)) /
    (Nat.choose N k : Real))

proposition_4_4 :
  exists y, SphereSection rho y
    and AtMostTwoValues y
    and forall z, SphereSection rho z ->
      sliceFunctional k z <= sliceFunctional k y
5

Two levels leave a hypergeometric count

Once \(y\) has two coordinate values, the slice sum is a centered hypergeometric count. Lemma 4.5 supplies the sharpened MGF bound.

\[ \log\E e^{t(H-m\mu)} \le \frac{t^2}{8}B_{N,m}, \qquad B_{N,m}=(N-s)^2 \sum_{\ell=N-s}^{N-1}\ell^{-2}. \] 
lemma_4_5_hypergeom_mgf :
  log (hypergeomMgf N K m t)
  <= (t ^ 2 / 8) * hypergeomB N m
6

Gamma evaluation, comparison, and optimality

The remaining algebra gives the closed form, asymptotics, the comparison with Barber's factor, and the lower bound showing that \(1/N\) inflation is unavoidable. 

gamma_eq_closed :
  Gamma N = GammaClosed N

gamma_asymptotic :
  Gamma N = 1 + 3 / (2 * N) + O(1 / N^2)

proposition_2_3 :
  AdmissibleConstant N C -> optimalLowerBound N <= C

Formalization milestones

  1. Projection algebra. Prove sum_projOnePerp_eq_zero and centeredWeightedSum_eq_dot_proj over Fin N.
  2. Endpoint computations. Verify Gamma 2 = 2 and epsilonBarber 2 = 1.
  3. Hamming-slice API. Build reusable lemmas for sliceSubsets, elemSym, and uniform slice averages.
  4. Analytic core. Formalize Hoeffding's lemma, the three-coordinate extremizer, and the hypergeometric martingale MGF bound.
