1 Overview

The theorem studies exchangeable random variables \(X_1,\ldots,X_N\in[-1,1]\) and weighted centered sums \(\sum_{i=1}^n w_i(X_i-\overline X_N)\). The proof first rewrites the statistic as a zero-sum projected dot product, then reduces the MGF bound to a Hamming-slice inequality and a hypergeometric martingale estimate.

Lean status. The current file introduces no global axioms. The hard paper-level facts are fields of ProofObligations; the exported theorem theorem_2_1 is proved from those fields.

3 Main theorem

Theorem 2.1, conditional Lean theorem

ExchangeableHoeffding.theorem_2_1
\[ \mathbb E\exp\left( \lambda\sum_{i=1}^{n}w_i(X_i-\overline X_N) \right) \le \exp\left( \frac{\lambda^2}{2}\Gamma_N \left\|P_{\mathbf 1^\perp}\widetilde w\right\|_2^2 \right). \]

In Lean this is derived from the zero-sum MGF statement and the two projection identities. It is not asserted as a global axiom.

Zero-sum reduction

ProofObligations.theorem_2_1_zero_sum
\[ \sum_i a_i=0 \quad\Longrightarrow\quad \mathbb E e^{\lambda\langle a,X\rangle} \le \exp\left(\frac{\lambda^2}{2}\Gamma_N\|a\|_2^2\right). \]
