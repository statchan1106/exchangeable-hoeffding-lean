Exchangeable Hoeffding bounds, from paper notation to Lean modules

This page aligns the paper A Sharper Hoeffding Bound for Weighted Sums of Exchangeable Random Variables with the modular Lean development in Testlean.Exchangeable_Hoeffding_ver2.

The theorem

For exchangeable \(X_1,\ldots,X_N\in[-1,1]\), centered weights are controlled by the projected vector \( \proj\widetilde w \), not by the unprojected zero-padded vector.

\[ \E\exp\{\lambda T_w(X)\} \le \exp\left\{ \frac{\lambda^2}{2}\Gamma_N \|\proj\widetilde w\|_2^2 \right\}. \]

Lean boundary

No global axioms are used. Proved finite facts and explicit theorem interfaces are separated so readers can see exactly what Lean checks now and what remains as analytic formalization work.

Main theorem

Paper statement

For \(n\le N\), \(w\in\R^n\), and \(\lambda\in\R\),

\[ \E\exp\left\{\lambda\sum_{i=1}^{n} w_i(X_i-\overline X_N)\right\} \le \exp\left\{\frac{\lambda^2}{2}\Gamma_N \|\proj\widetilde w\|_2^2\right\}. \]

Lean statement

Reduction checked from explicit interface 
theorem theorem_2_1 (P : MainProofObligations)
    {N n : ℕ} (hN : 2 ≤ N) (hn : n ≤ N)
    (μ : Measure (Fin N → ℝ)) [IsProbabilityMeasure μ]
    (hEx : Exchangeable μ) (hBd : BoundedByOne μ)
    (w : Fin n → ℝ) (lam : ℝ) :
    (∫ x, Real.exp (lam * centeredWeightedSum hn w x) ∂μ) ≤
      Real.exp (((lam ^ 2) / 2) * Gamma N *
        normSq (projOnePerp (zeroPad hn w)))

Proof map

1

Centering becomes projection

Set \(a=\proj\widetilde w\). Lean proves \(\sum_i a_i=0\) as sum_projOnePerp_eq_zero, and defines centeredWeightedSum by the projected dot product \(\langle a,x\rangle\).

2

Exchangeability supports symmetrization

The declaration Exchangeable says every coordinate permutation preserves the law. The theorem exchangeability_supports_symmetrization names the paper line \(X_\pi\stackrel d=X\).

3

Vertices become Hamming slices

Vertices with \(k\) plus signs become uniform \(k\)-subsets after symmetrization. The target is the slice inequality.

\[ \log\E_{S_k}\exp\left\{\sum_{i\in S_k}y_i\right\} \le \frac{\Gamma_N}{8}\|y\|_2^2. \] 
slice_inequality :
  Real.log (sliceAverage k
    (fun S => Real.exp (∑ i ∈ S, y i))) ≤
      (Gamma N / 8) * normSq y
4

The slice maximizer has at most two levels

ThreePoint supplies the three-coordinate extremizer interface used by HammingSlice. The central conclusion is that the worst slice input has at most two coordinate values.

Two levels leave a hypergeometric MGF

Once \(y\) has two values, the slice sum is a centered hypergeometric count. The needed factor is \(B_{N,m}=(N-s)^2\sum_{\ell=N-s}^{N-1}\ell^{-2}\). 

lemma_4_5_hypergeom_mgf :
  Real.log (hypergeomMgf N K m t) ≤
    (t ^ 2 / 8) * hypergeomB N m

Sharpness and comparison

Gamma behavior

The paper proves \(\Gamma_N=1+3/(2N)+O(N^{-2})\) and \(\Gamma_N<1+\varepsilon_N\) for every \(N\ge3\), with equality at \(N=2\).
