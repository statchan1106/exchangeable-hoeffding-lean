A Sharper Hoeffding Bound for Weighted Sums of Exchangeable Random Variables

Seongchan Lee and Ilmun Kim

A Lean 4 project for organizing and formalizing the proof architecture of a sharper Hoeffding-type moment generating function bound for centered weighted sums of bounded exchangeable random variables. The current Lean development follows the submitted TeX notation, isolates the remaining analytic ingredients in an explicit no-global-axiom interface, and checks that the stated main theorem follows from those named ingredients.

Current verification boundary

The main Lean theorem is conditional on ExchangeableHoeffding.ProofObligations. This keeps the trusted environment free of global axioms while making each remaining mathematical ingredient visible as a named target. In other words, Lean currently verifies the reduction from the named lemma interface to Theorem 2.1. The goal of the project is to replace each field of ProofObligations by a complete Lean proof.
